# FileXorProcessor

🛠️ **FileXorProcessor** — консольная утилита на C++ с использованием Qt, предназначенная для модификации содержимого файлов с помощью побитовой операции XOR. Поддерживает обработку по маске, многопоточность, периодический режим, автоудаление и безопасную работу с большими файлами.

## 🚀 Возможности

- Поддержка файлов любой длины (включая гигабайтные) — поблочная обработка.
- Многопоточная обработка файлов через `QtConcurrent::run`.
- Побитовая XOR-модификация с заданным 8-байтным значением.
- Удаление исходных файлов по желанию.
- Настраиваемая маска поиска входных файлов (например, `*.txt`, `*.bin`).
- Повторяющийся запуск по таймеру или однократный запуск.
- Обработка конфликта имён выходных файлов (перезапись или добавление счётчика).
- Прогресс и статус обработки в консоли.

## 🧩 Используемые технологии

- C++17
- Qt 6 (Core, Concurrent)
- MinGW (или любой другой компилятор, поддерживаемый Qt)
- CMake или qmake
